# Shared method-draft prose revision

> 从源码根目录执行命令。`$runtime` 是用户已确认可用的依赖目录；源码 ZIP 不含该目录。路径均为可替换的示例。

```powershell
$runtime = 'C:/Meta Runtime'
$rscript = Join-Path $runtime 'native/R/bin/Rscript.exe'
$env:META_PYTHON = Join-Path $runtime 'native/python/python.exe'
$env:META_RSCRIPT = $rscript
$env:META_R_LIBRARY = Join-Path $runtime 'libraries/r-extended'
$env:META_METHOD_PYTHON_LIBRARY = Join-Path $runtime 'python/standard'
$env:META_FRONTEND_PYTHON_LIBRARY = $null
$env:PYTHONPATH = $env:META_METHOD_PYTHON_LIBRARY
$env:PYTHONUTF8 = '1'
```


After a method-specific non-final Word draft has been produced, run `./launch.cmd meta method-revise --draft EXISTING_PAPER_DIR --changes changes.json --out NEW_DIR`. The command works on drafts generated by the standard-library method Word renderer, including the diagnostic and sparse-event routes. It verifies each existing draft member against `manifest.json`, copies the statistical figures/tables and source-review attachments unchanged, revises the matching Markdown and Word paragraph and any structured `manuscript.json` section, and emits a new manifest, `revision_receipt.json`, and `attachment_index.json`. The prior draft directory remains intact. The output is a **draft**, with Word visual review reset to false.

`changes.json` has schema `meta-method-prose-revision-v1`, `prior_manifest_sha256` equal to the existing draft manifest hash, nonempty `reviewer` and `reason`, and `edits` containing `section`, `old_text`, `new_text`. Each old paragraph must occur exactly once in both the named Markdown section and the Word document. Only `Introduction` and `Discussion` prose can be changed. Methods, Results, references, tables, and numeric facts are locked; new evidence or a changed model requires a fresh analysis and manuscript build. Revision text is a reviewer claim and is **not** automatically checked against original articles or for all scientific contradictions. The receipt binds the old draft and change file but does not authenticate a person or implement Word tracked changes.
